# Tauri + React

This template should help get you started developing with Tauri and React in Vite.

## Network printing

Install and configure the printer on the receiving computer using its normal
operating-system printer setup first. When both computers are connected to the
same OneForAll network, the Print view lists printers advertised by the other
peers. Choose a local document and a destination printer; the receiving peer
must approve the request before the document is sent to its OS print spooler.
The sender and receiver see the resulting job status in the Print view.

Document format support is determined by the receiving computer's printer
driver and OS printing support. A completed job means the OS accepted it for
printing; it does not confirm that paper physically came out of the printer.
